Using display: inline-block; you can put elements in your page which have block characteristics like height and vertical margins, but which are treated like inline elements for layout purposes. They don't create a new block context, they don't cause a line break, and they have an implicit width based on the size of their content, rather than taking up the full width of the viewport.

vertical-align: baseline (default), middle, top, bottom, super, and sub, and text-top
