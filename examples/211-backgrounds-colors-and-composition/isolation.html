isolation: auto (default) vs isolation: isolate

isolation: auto

Blends with page too

The heading and copy use mix-blend-mode: difference. Because this panel is not isolated and has translucent layers, the blend includes the page background behind the card. As the page animates, these colors shift.

isolation: isolate

Blends only inside

This panel creates its own stacking context, so the blend is computed only against the panel’s own (semi-transparent) background image. The page’s animated background no longer affects the text.

Watch the page background animate: on the left, the text color changes with it; on the right, it stays stable thanks to isolation: isolate.
