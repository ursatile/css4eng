isolation: auto vs isolate — with mix-blend-mode: difference

isolation: auto

Blends with page too

The text uses mix-blend-mode: difference, so it also reacts to the page background behind this card. Toggle the background to see it shift.

isolation: isolate

Blends only inside

This card creates a new stacking context. The blend is computed only against the card’s own background, staying stable even as the page changes.

Tip: On the left, the heading color changes noticeably whenever the page background changes, because it’s blending with everything behind the card. On the right, isolation confines the effect to the card itself.
